# Солнечный калькулятор Delta 500

Калькулятор выработки и экономии для солнечных панелей Delta PV TOP 500 Вт. Паспорт модуля находится в `panel.pdf`. Сайт статический: его можно открыть на GitHub Pages или выложить в корень любого хостинга. Локально он запускается из корня проекта командой `python3 -m http.server 8080`.

- [Расчёт по крыше](https://mikhail228777.github.io/solar-calculator-delta-500/) — основная страница в 4 шага. Клиент находит дом по адресу или по геопозиции и отмечает на спутниковом снимке линию А и линию Б. Затем выбирает тип крыши и указывает платёж за свет или площадь дома. Калькулятор раскладывает панели на крыше, подбирает станцию под потребление и показывает экономию, окупаемость, выработку по месяцам и аккумуляторы.
- [Подробный калькулятор для дома](https://mikhail228777.github.io/solar-calculator-delta-500/home.html) — резерв при отключении, средняя дневная выработка по сезону и экономия по счёту за свет.
- [Для предприятий](https://mikhail228777.github.io/solar-calculator-delta-500/industry.html) — годовая экономия после обслуживания и простая окупаемость по введённой цене станции.
- [Формулы и исходные данные](https://mikhail228777.github.io/solar-calculator-delta-500/methodology.html) · [PDF](https://mikhail228777.github.io/solar-calculator-delta-500/methodology.pdf).

## Расчёт по крыше

- **Площадь.** Первые две точки задают линию А, третья — линию Б, перпендикулярную А. Площадь равна А × Б. Углы можно перетаскивать, а размеры — ввести вручную.
- **Скатная крыша.** Клиент отмечает только скат под панели и выбирает, куда он смотрит (юг, юго-восток или юго-запад, восток или запад, север) и уклон (20°, 30° или 45°). Сторона, идущая вдоль ската, удлиняется на 1 / cos(уклона). Панели кладутся по скату с отступом 0,3 м от края, в книжной или альбомной ориентации — где помещается больше.
- **Плоская крыша.** Ряды смотрят на юг под оптимальным для широты углом по формуле Jacobson & Jadhav (2018): для Ростова-на-Дону это 34°. Расстояние между рядами рассчитано по высоте солнца в полдень 22 декабря, 90° − широта − 23,44° (не ниже 12°), чтобы ряды не затеняли друг друга. Поэтому чем севернее дом, тем реже ряды. Отступ от края — 0,5 м.
- **Потребление.** Берётся платёж за свет, делённый на тариф. Если платёж неизвестен, для дома считается 150 кВт·ч + 2 кВт·ч на м² в месяц.
- **Размер станции.** Число панелей подбирается так, чтобы за год они выработали примерно столько же, сколько тратится. Верхняя граница — вместимость крыши, а для частного дома ещё и 30 панелей (15 кВт, предел микрогенерации). Ползунок позволяет выбрать любое число.
- **Выработка и экономия.** Считаются функцией `calculateSolar` из `solar.js` по данным NASA POWER. Дом сразу тратит 60% выработки, бизнес — 85%. Излишки в экономию не входят.
- **Аккумуляторы.** Модули по 5 кВт·ч, полезно 90%. Их число рассчитано на половину суточного потребления. Резерв указан для нагрузки 300 Вт.
- **Условные значения.** Тариф 7 ₽ за кВт·ч и цена 70 000 ₽ за кВт для дома, 10 ₽ и 60 000 ₽ для бизнеса. Их можно поменять на странице результата и в константе `MODES` в `roof.js`.
- **Ссылка на расчёт.** Расчёт сохраняется в адресе страницы после `#`, поэтому ссылку можно переслать.

## Архив солнечных данных

`data/nasa-power-climatology.json` содержит 2 679 ячеек в пределах 41–60° с. ш. и 19–160° в. д. Данные извлечены из [помесячной выгрузки NASA POWER](https://github.com/hssaleh/Heat-Route-to-Firm-H2/blob/2cacb152e327a3246be186a40f83c2bcf6bc75e7/data/nasa_param_GHI.csv) с сохранением исходных значений по месяцам. Единицы измерения — кВт·ч/м² за средние сутки месяца. Значения за пределами сетки запрашиваются через API. Первоисточник — NASA Langley Research Center POWER Project. [Условия использования данных](https://registry.opendata.aws/nasa-power/).

## Как считается результат

По свободной площади ската калькулятор оценивает верхнюю границу числа модулей. Площадь делится на 1,961 × 1,134 м и результат округляется вниз. Для 30 м² это до 13 модулей, или 6,5 кВт. Можно выбрать меньше панелей. Для раскладки по конкретной крыше нужны размеры и форма каждого ската, места для проходов и отступы.

Мощность станции равна количеству модулей, умноженному на 0,5 кВт. Для выработки берутся инсоляция местности, наклон, азимут и потери системы 20%. Экономия учитывает долю собственного потребления и ограничивается средним месячным потреблением. Для дома принята доля 60%, предприятие указывает её по своей нагрузке.

Простая окупаемость равна цене с монтажом, делённой на годовую экономию после обслуживания. Резерв для дома рассчитывается по ёмкости, начальному заряду и средней нагрузке с КПД разряда 90%. Суточная выработка показывается отдельно по выбранному месяцу. Подробные формулы и примеры приведены в [методике](./methodology.html).

## Проверка

Workflow «Map preview» открывает опубликованную страницу в Chrome и пишет в лог, какая карта загрузилась (`yandex` или `esri`). Там же — снимок карты в base64 между строками `PREVIEW-BEGIN` и `PREVIEW-END`.

GitHub Actions проверяет публикацию всех страниц и методики. Он сверяет числовые результаты примеров на архивных данных, раскладку панелей на крыше 10 × 10 м и ответы Photon, Esri, OpenStreetMap и NASA POWER. Итог каждого запроса виден на вкладке Actions.

## Публикация на GitHub Pages

Загрузите содержимое архива в корень отдельного репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Для этой сборки достаточно статического хостинга.

## Публикация на обычном хостинге (например, Reg.ru)

Распакуйте архив сайта в корневую папку домена (в ISPmanager это обычно `www/имя-домена`). Нужны все файлы, кроме папки `.github` и README. Сайт работает только по HTTPS, иначе браузер не даст определить местоположение. Сервер не нужен: страницы, скрипты и данные о солнце лежат в файлах, а карта, снимки и поиск адреса загружаются напрямую из браузера.
